# 扒剧 v1.1 — 从视频到「运镜分镜表 + 剧本」

v1.1 变更（2026-11-15，用 210 秒双时空短剧《特工姜依》实测）：新增 §8 转场/闪回/双时空识别（含 `signalstats` 亮度跳变法）、§9 打戏与群戏的采样参数。原 §8 的"待验证"项已被实测替换。

核心结论（v1.0 相对旧做法的唯一实质升级）：

> **单帧 = 构图，连续帧 = 运动。构图看一帧就够，运镜和主体运动必须靠帧间差分。**

一张 1.6 秒的代表帧能读出"蛇在梁上"，读不出"蛇沿梁绕柱爬下来"。凡是写出"镜头推近/横移/跟随""人物走到窗边""手慢慢松开"这类句子，都必须是看过连续帧之后的结论，否则一律降级为静态构图，不许写运动。

## 1. 元数据与切点

1. `video_probe` 拿时长、分辨率、帧率、字幕轨。
2. `video_storyboard({dryRun:true})` 看切点数与档位建议（不出图、不花 image token）。
3. `video_storyboard({detail:"low", ocr:true})` 取每镜 1 帧的构图索引，记下每个 cell 的时间码。

到这一步只有"构图清单"，**还不能写运镜**。

## 2. 4fps 连拍（本 skill 的关键动作）

按 15–22 秒切片，每段抽 4fps 拼成带时间码的图（5×8 或 6×10 网格）：

```powershell
$ff  = "C:\Users\PC\.dsh\tools\ffmpeg\bin\ffmpeg.exe"
$vid = "C:\path\video.mp4"
$dir = "C:\path\out"

& $ff -y -ss 15 -t 20 -i $vid `
  -vf "fps=4,scale=330:-1,drawtext=text='%{pts\:hms}':x=6:y=6:fontsize=15:fontcolor=yellow,tile=5x8" `
  -frames:v 1 "$dir\_sheet_15_35.png"
```

- `fps=4` 默认；打斗/转身/群戏用 6；慢戏 2 够。
- `scale=330` + `tile=5x8` → 1650×1488，单格 ~330×186，能看清人物动作与方位。
- `drawtext %{pts\:hms}` 烧时间码；**`-ss` 之后 pts 归零**，读图时自己加段起点秒数。
- 一张图覆盖 5–8 个镜头。

读图顺序（写结论必须按这个来）：
1. **主体位移**：同一主体在格 1 与格 N 的位置差 → 走了/爬了/扑向谁。
2. **画框变化**：背景（门窗、柱子）在格间变大/变小/平移 → 推 / 拉 / 摇 / 移 / 升降。
3. **入画出画**：从哪条边进、往哪条边出。
4. **遮挡与画框构图**：前景遮挡、门框/窗框（偷窥戏几乎必有）。
5. 以上都无变化，才写"固定机位"。

## 3. 台词与硬字幕

- 有字幕轨：`video_locate` 或直接读轨。
- 只有硬字幕：`video_subtitles({maxStrips, stepSec})` 出条带图，**只当初稿**——3 秒一采样会截断句子、认错字。
- 关键句必须用 §2 连拍图复核（同一句横跨 6–12 格，能看全）。实测错误：
  - 「你若敢拒嫁，**全寨几百条人命都要给你殉葬**」被读成"你要看着全寨的人为你死绝吗"。
  - 「**连夜**去找心上人竹马」被读成"连他去找…"。
- 分配说话人看口型：张嘴的帧要与该句时间码重叠。

## 4. 运镜分镜表

一镜一行，列固定：

| 时间码 | 景别 | 运镜 | 画面/主体动作 | 台词·字幕 | 音效 |
|---|---|---|---|---|---|

- **景别**：大远/远/全/中/近/特/大特。
- **运镜**：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 甩 / 手持，可加"缓/急"。
- **画面/主体动作**：只写看得见的（谁、在哪、做什么、朝向），不写心理。
- **音效**：能推断的写（如"灯笼落地"），不确定留空，别编。

反例：把"蛇首在梁间移动"写成"鳞片贴着地面碾过"——单帧看不出高低差，连拍一眼就能看出是横梁。

## 5. 转剧本（Kenny SOP 1.7.2 严格版）

1. 首行 `第1集`；场序 `x-x 地点 内|外 日|夜 人物：A、B`；**内/外、日/夜二选一，禁止 `/`**；每集 ≤5 场。
2. **无空行**。
3. 画面行以 `▲` 开头；**每句台词/OS/VO 前必须有独立 ▲**；连续 ▲ ≤2（闪回/蒙太奇 ≤3）。
4. 台词 `角色名（情绪或动作）：台词`。
5. `[音效：xxx]` / `[环境音：xxx]` 挂在画面行内，不能单独占行，也不能用来隔开连续台词；每场 1–3 个，全集 ≥6。
6. `OS` = **独白**，角色没说出口的心里话（人在画面里也能用）；`VO` = **台词配画面**，角色确实说出口了，但声音压在别的画面上、人不在画里。把"人不在画面里的台词"写成 OS 是最常见的错——那是 VO。
   合计 **OS+VO ≤60%**（本组口径；Kenny SOP 原文写 20%，以用户口径为准），且**不得连续 3 行以上 OS/VO**。
   `OS` 必须像真人开口：短、口语、不许写书面旁白。
   ✗ 「成了我晦暗岁月里活下去的全部希望」
   ✓ 「就那点暖，撑了我这么些年。」
7. 时间只用"日/夜"。
8. 汉字 **800–1000**。
9. 主要角色首次出场在画面行标 `【字幕：角色名】`，同一人不重复；功能性小角色不标。
10. 闪回：`【闪回】`、`【闪回结束】` 各占一行，闪回内的场也要独立场序。
11. **忠于原料**：角色说出口的台词只用视频里出现过的原句，不新增、不改写、不合并；画面可写细，不能编剧情。**唯一例外是 OS 独白**——保留原意，但允许改成口语短句（用户明确要求 OS 要像真人说的，不要书面旁白）。
12. 结尾 `【场景汇总】`，每场一行。

写作顺序：先把分镜压成 3–5 场（爆点前置：0–3 秒抓眼、3 秒抛冲突、15 秒内首反转）→ 补 ▲ 与音效 → 跑 §6 自检。

**把分镜写成剧本、或判断某一行是不是编的，接 `juben` skill**（`C:\Users\PC\.agents\skills\juben\SKILL.md`）：**台词一字不能改**（原片字幕是死文本，只能标注 O.S./V.O. 与校对备注）；能写的只有 ▲ 行。它给的是——静帧四层分账（已见/可推/不可读）、帧间运镜七判据（摇与移靠视差分层分开）、动作→意图→代价三层闸门（四种情况必须停在物理动作）、视线与遮挡的"可被谁看见"表、视听语言可判定阈值（景别差 ≥2 级才判权力反转、光比 4:1、俯仰 ±10/15/20°）、表演可拍摄词表、三档写法与 `[待补拍/核查：…]` 占位符、存疑清单。交付物固定四件：剧本 ＋ 存疑清单 ＋ 不可读清单 ＋ 补拍清单。

## 6. 机器自检（必跑）

存成 `_check.py`，用 bundled python 跑；**不要 print 中文**（GBK 控制台会 `UnicodeEncodeError`），写文件再读：

```python
import re, io, sys
p = sys.argv[1]
t = io.open(p, encoding="utf-8-sig").read()
lines = t.splitlines()
han    = len(re.findall(r"[\u4e00-\u9fa5]", t))
arrows = [l for l in lines if l.startswith("▲")]
blanks = sum(1 for l in lines if not l.strip())
dlg    = [l for l in lines if "：" in l and not l.startswith("▲")
          and not l.startswith("【") and not re.match(r"^\d+-\d+\s", l)]
osvo   = [l for l in dlg if "OS" in l or "VO" in l]
sfx    = re.findall(r"\[(?:音效|环境音)：[^\]]+\]", t)
slash  = re.findall(r"内/外|外/内|日/夜|夜/日", t)
mx = run = 0
for l in lines:
    run = run + 1 if l.startswith("▲") else 0
    mx = max(mx, run)
ratio = round(len(osvo) / max(1, len(dlg)) * 100)
mxov = curv = 0
for l in dlg:                      # 连续 OS/VO 不得 ≥3 行
    curv = curv + 1 if ("OS" in l or "VO" in l) else 0
    mxov = max(mxov, curv)
res = (f"汉字={han} ▲={len(arrows)} 连续▲max={mx} 空行={blanks} 斜杠={len(slash)} "
       f"台词={len(dlg)} OS+VO={len(osvo)}({ratio}%) 连续OS/VO max={mxov} 音效={len(sfx)} "
       f"字幕={len(re.findall(chr(0x3010)+'字幕：', t))}")
io.open(p + ".chk.txt", "w", encoding="utf-8").write(res + "\n" + "\n".join(osvo))
```

通过阈值：

| 指标 | 合格 |
|---|---|
| 汉字 | 800–1000 |
| 连续 ▲ | ≤2 |
| 空行 | 0 |
| 内/外、日/夜斜杠 | 0 |
| OS+VO 占比 | ≤60%，且连续 OS/VO ≤2 行 |
| 音效+环境音 | ≥6（每场 1–3） |
| 【字幕：】 | 主要角色数且不重复 |
| 自编台词 | 0 |

**自编台词比对**（第 11 条最易翻车）：把每句台词去标点后取 8 字窗口，回原料文本查子串，全部命中才算过；有落空就是编的，回退重写。

## 7. 坑位清单

1. **单帧当运动**：最贵的错。推/移/跟/爬/走近 一律来自 §2 连拍图。
2. **条带 OCR 认错字**：关键句必须用连拍图复核。
3. **拼图时间码归零**：`-ss` 后 `%{pts}` 从 0 起，读图加段起点。
4. **Python 打中文崩**：写文件再读。
5. **临时目录权限**：沙箱只允许写 workspace，脚本与输出都放 `扒剧测试\`，别写 `%TEMP%`。
6. **`strategy:"full"` 不是更完整**，是最贵；`auto`/`compact` 更划算。
7. **无 ASR 时别只说"我听不到"**：说明"画面正常、台词靠硬字幕 OCR"，并给装 ASR / 换有字幕轨素材两条路。
8. **场次凑数**：为塞台词而打乱分镜顺序是隐性失真，宁可并场或走 OS。
9. **`metadata=print:file=` 带盘符**：`file=C:/x.txt` 会被解析成"选项名"，必须用相对路径并把工作目录切到输出目录。
10. **`-f null NUL`**：Windows 上 ffmpeg 报 `Error opening output file NUL`，一律用 `-f null -`。
11. **blackdetect 漏暗场**：淡出不等于纯黑，回忆切入常被漏掉；用 §8.1 亮度跳变兜底。

## 8. 时间结构：转场 / 闪回 / 双时空（v1.1 已验）

只在看图里"感觉变了"是不够的，先机器定位时间跳点，再去图上确认。

### 8.1 亮度跳变法（主力，比 blackdetect 灵）

```powershell
# 必须先把工作目录设到输出目录：file= 里出现盘符冒号会被当成选项分隔符
# 正确：file=_yavg.txt（相对路径）；错误：file=C:/xxx  → "No option name near ..."
& $ff -loglevel error -i $vid `
  -vf "fps=2,signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=_yavg.txt" `
  -an -f null -
```

- 输出每帧 `pts_time` + `YAVG`（平均亮度），2fps 足够定位转场。
- 判据：**相邻采样 `|ΔYAVG| > 25`** 记为跳点；`YAVG < 20` 记为暗场（淡出/黑场）。
- 再用 §2 连拍图确认跳点两侧是不是换了时/空。
- 实测《特工姜依》210 秒 420 个采样点，跳点 21 个，其中 37.0/37.5（切入"十二岁那年"回忆）、95.5/96.0（血书黑场）、197.5–199.0（剧名卡+爆炸）全部命中。

### 8.2 blackdetect 只做补充

```powershell
& $ff -i $vid -vf "blackdetect=d=0.10:pix_th=0.20" -an -f null - 2>&1 | Select-String "black_start"
```

- `d=0.15:pix_th=0.10` 太严，210 秒只抓到 1 处；`d=0.10:pix_th=0.20` 抓到 3 处。
- **暗场淡出不是纯黑**，所以 blackdetect 会漏掉真正的回忆切入——永远配 8.1 一起用。
- `-f null NUL` 在 Windows 上会报 `Error opening output file NUL`，用 `-f null -`。

### 8.3 闪回的四条判据（满足 ≥2 条即判闪回）

1. 亮度跳点 / 黑场在跳点处（8.1）。
2. 画面内有**时间字幕卡**：「十二岁那年宫宴」「四年了」「两日后」「五年前」——这类竖排或角落小字最容易被当成道具文字漏掉。
3. 人物**年龄、服饰、发型、妆造**变化（同一演员变小/变素）。
4. 色调与画质变化（回忆常偏暖、低饱和、轻雾）。

### 8.4 双时空（穿越/系统流）的判据

- 画风整体切换：3D 古装 ↔ 现代实拍/赛博。
- 画面内出现**现代 UI**：代码屏、进度条、电脑、手机。
- 侧边竖排**剧名/角标**（如「特工姜依」）——出现即进入另一条时空线或片头。
- 处理：双时空不是闪回，剧本里不要硬套 `【闪回】`；应按两个时空各自开篇，或用 OS/VO 交代，否则破坏 SOP 第 10 条。

## 9. 打戏 / 群戏的采样（v1.1 已验）

| 类型 | fps | 网格 | 额外动作 |
|---|---|---|---|
| 近身缠斗（掐脖、按榻、吐血） | 5–6 | 10×10 | 每镜首/中/尾裁切放大读手部与头部朝向 |
| 招式清晰的对打（出拳、侧踢） | 8–10 | 8×8 | 单镜单独出一张，缩到 1 个镜头 |
| 群戏（宴席、朝堂、灯会） | 2–3 | 10×6 | 另取一张**原分辨率单帧**看队形与群演是否同步 |
| 长镜头调度 | 4 | — | 直接看连拍，别信单帧 |

- 打戏 5fps 能判"谁压制谁、往哪边倒、什么时候吐血"，判不出招式名；要写"一记反手擒拿"这种细节必须 8fps 以上并逐镜裁切。
- 群戏 3fps 只能数站位与对称；要判"镜头是否横移扫过人群"用 4fps。
- 大场面单帧用 `-ss <中点> -frames:v 1` 取原始 1920 宽，别用拼图格。

实测标注（《特工姜依》）：163–183 秒近身压制段（掐脖→按倒→吐血→咆哮）5fps 可完整拆出 7 个动作节点；204.7–206 秒现代格斗 3fps 时会糊成一片，必须 8fps；91–95.3 秒朝堂（金漆龙椅 + 两列甲士 + 群臣）3fps 即可读出对称构图与缓推。

## 10. 待验证 / 下一版
