# Demian Drama Strip 扒剧

把一个短剧/短视频扒成两样能直接用的东西：**运镜分镜表** 和 **可拍摄剧本**。

安装后会在技能目录里多出一个 `demian-drama-strip` 技能，agent 在你要求"扒剧 / 把视频转剧本 / 拆一下这个短剧 / 出分镜表"时自动加载，也可以直接点名调用。

## 它解决的真正问题

拿一帧代表帧去描述一个镜头，只能读出**构图**。运镜、主体运动、"蛇从屋顶横梁绕柱爬下来"这种事，必须看**连续帧的差分**。这个技能的全部方法论就一句：

> 单帧 = 构图，连续帧 = 运动。凡是写"镜头推近 / 横移 / 跟随 / 某人走到窗边"，都必须是看过连续帧之后的结论，否则一律降级成静态构图，不许写运动。

配套的四件硬工具：

| 要做的事 | 用什么 | 为什么 |
|---|---|---|
| 切点与构图 | 分镜工具（每镜 1 帧） | 便宜，只当构图用 |
| 运镜 / 主体运动 | **ffmpeg 4fps 连拍 + tile 拼时间码图** | 帧间差分是唯一可靠的运动来源 |
| 台词 | 硬字幕**底部条带**裁切拼图 | 比条带 OCR 准，读错字是常事 |
| 转场 / 闪回 / 双时空 | `signalstats` 亮度跳变（`\|ΔYAVG\|>25` 跳点、`<20` 暗场） | `blackdetect` 会漏掉淡出型回忆切入 |

## 装上之后能做什么

- 一集 98 秒的 AI 国风短剧 → 5 张连拍图读出 60 个镜头，指出"蛇在梁上绕柱"这类单帧会漏掉的运动。
- 一集 210 秒双时空短剧 → 定位 0:37 的回忆切入（黑场 + 时间字幕卡 + 妆造变化），拆出缠斗型打戏与现代格斗的采样差异，认出"剧名竖排角标 + 代码屏"是双时空而不是闪回。
- 同样的素材 → 按 Kenny SOP 1.7.2 严格版出 800–1000 字、≤5 场、`▲` 画面行、`角色（情绪）：台词`、OS/VO 有上限、音效带方括号的剧本，并跑脚本自检字数、场次、连续 `▲`、OS/VO 占比。

## 安装

```bash
dsh plugin --profile <profile> add dsh-demian-drama-strip
```

从 GitHub 装（还没发 npm 时用这条）：

```bash
dsh plugin --profile <profile> add github:demian-1013/dsh-demian-drama-strip
```

本地开发目录安装（不发布也能用）：

```bash
dsh plugin --profile <profile> add <这个目录的绝对路径>
```

装完重启一次（新 bundle 首次激活），然后在技能清单里应该能看到 `demian-drama-strip`。

## 依赖

- **ffmpeg**：连拍、拼图、裁字幕带、亮度统计全靠它。不在 PATH 时技能里给了"先 `Get-Command ffmpeg`，再退回实测路径"的顺序。
- **Python 3**：只为剧本自检脚本（正则统计），没有它也能写剧本，只是自检要手算。

不依赖任何联网服务，不读凭据，不写工作区之外的文件——除了它自己产出的分镜图和 `.md` 报告。

## 已知边界

- 打戏：近身缠斗 5–6fps 够用；**真正的招式/兵器格斗要 8–10fps**，3fps 会糊成一片。
- 群戏：密度型（人海）用 2–3fps 看走位即可；对称型（朝堂/列阵）要额外取一张原分辨率单帧看构图。
- 无字幕轨、本机又没配 ASR 时，台词只能靠画面硬字幕；两者都没有就必须明确告诉用户"这是没台词的版本"，不能编台词。
- 闪回里再闪回、双时间线交叉剪辑，目前只有判据没有实测样本。
